# Security policy

IsoTrack keeps health data on the device, so we take reports that could expose
it seriously, for example data leaking outside the App Group container or into
logs, widgets, shortcuts or shared summaries in a way the user didn't intend.

Please **don't open a public issue** for a vulnerability. Report it privately
through GitHub instead: on this repository, open the **Security** tab and click
**Report a vulnerability**.

Only the latest release is supported.
